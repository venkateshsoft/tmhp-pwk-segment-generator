
TMHP 837 PWK Segment Generator Tool
====================================

This is a standalone offline web tool to generate TMHP-compliant PWK segments.

How to Use:
-----------
1. Open index.html in any modern browser.
2. Fill in all required fields:
   - Phone Number (10 digits)
   - Insurance Address (max 18 chars)
   - City (max 20 chars)
   - State Code (2 letters)
   - ZIP Code (5-9 digits)
   - Disposition Date (YYYYMMDD)
   - Payer Position (Primary, Secondary, Tertiary)
3. Click "Generate PWK Segments" to view the output.
4. Click "Copy Bold PWK06" to copy the bold PWK06 values to clipboard.

Security:
---------
- This tool runs entirely offline.
- No data is transmitted or stored.
- Safe for use with sensitive information.

Files:
